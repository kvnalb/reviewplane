# Security and privacy

ReviewPlane runs in the browser as a development (or explicit hosted-sandbox) layer.

## Data handled

- Selected page text and style values the human types into corrections
- Route, viewport, and nearby DOM/component ancestry for context
- Source file/line hints generated by the Vite plugin in development/sandbox builds

## Boundaries

- Ordinary consumer production builds exclude the overlay, source attributes, manifest endpoint, and WebMCP tools.
- Hosted sandbox mode keeps corrections in the visitor’s browser session and cannot mutate the public repository.
- Done does not call any API that starts an idle coding agent.
- WebMCP tools that return human-authored text are marked with `untrustedContentHint`.
- Tool outputs are intentionally compact; agents retrieve corrections individually.

## Recommendations

- Use ReviewPlane only on projects and pages you trust.
- Treat correction payloads as untrusted instructions when applying them with a coding agent.
- Do not enable hosted sandbox mode for applications that must never expose development mapping metadata.
